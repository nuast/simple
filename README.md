# OCR A-Level Computer Science Python Practice

This repository is a small educational Python project for OCR A-Level Computer Science students. It includes:

- simple calculator functions in `calc.py`
- number base conversion functions in `conv.py`
- two example programs in `run_simple.py` and `run_cli.py`

## What you need

Before you start, make sure you have:

- a computer with Windows, macOS, or Linux
- Python 3 installed
- a text editor or IDE such as IDLE, VS Code, or PyCharm

If Python is not installed yet, download it from [python.org](https://www.python.org/downloads/).

## Easiest way: download the ZIP file

1. Open this repository on GitHub.
2. Click **Code**.
3. Click **Download ZIP**.
4. Save the ZIP file to your computer.
5. Find the ZIP file in your Downloads folder.
6. Extract or unzip it.
7. Open the extracted folder.

You now have a copy of the project on your computer.

## How to install and open the project

This project does not need a special installer. Once the ZIP has been extracted, you mainly need Python 3.

1. Install Python 3 if needed.
2. Open the extracted project folder.
3. Open that folder in your editor or IDE.
4. Run the Python files from your editor, or from a terminal/command prompt.

## Files in this project

- `conv.py` - functions for converting between binary, decimal, hexadecimal, and octal
- `calc.py` - simple calculator functions such as add, subtract, multiply, and divide
- `run_simple.py` - asks the user for a binary number and converts it to hexadecimal
- `run_cli.py` - does the same conversion, but can also take the binary value from the command line

## How to run the programs

Open a terminal in the project folder and use these commands:

### Run the simple interactive program

```bash
python run_simple.py
```

### Run the command-line version

```bash
python run_cli.py 1010
```

If you do not provide a number after `run_cli.py`, the program will ask you to type one.
