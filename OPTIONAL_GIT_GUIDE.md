# Optional: Git Clone and GitHub Desktop

Downloading the ZIP file is the easiest option for most students. If you are starting to learn version control, these options are useful extras.

## Option 1: `git clone`

Use this in a terminal:

```bash
git clone https://github.com/nuast/simple.git
```

### Advantages of `git clone`

- easy to get the full repository in one command
- easier to download updates later with Git
- useful for learning real development workflows
- helps you track your own changes

## Option 2: GitHub Desktop

GitHub Desktop gives you a graphical way to work with Git and GitHub.

1. Install GitHub Desktop from [desktop.github.com](https://desktop.github.com/).
2. Open GitHub Desktop.
3. Choose **Clone a repository from the Internet**.
4. Select or paste the repository URL.
5. Choose where to save it on your computer.
6. Click **Clone**.

### Advantages of GitHub Desktop

- easier for beginners who prefer buttons and menus
- shows changed files clearly
- makes commits and syncing simpler
- helpful for coursework practice with version control

## Which method should you choose?

- Choose **Download ZIP** if you only want the files quickly.
- Choose **git clone** if you want to learn command-line Git.
- Choose **GitHub Desktop** if you want Git features with a visual interface.
